## How we choose criteria

- **Measurable.** Every criterion is read from the page, the server or the site, never guessed.
- **Documented.** Each one is backed by the search engines' own documentation (Google Search Central, Bing Webmaster
  Guidelines, the AI vendors' crawler pages) or a named study. The sources are listed under each group.
- **No padding.** A smaller honest list beats a long one with myths in it, and an explanation never claims more
  than its source says.
- **Your choices stay yours.** Training crawlers (GPTBot, ClaudeBot, CCBot…) are listed but never scored: allowing
  them is a business decision and doesn't affect AI search.
- **No promises.** Passing every check removes obstacles. Nobody can guarantee rankings or AI citations.

## Each criterion comes with

- why it matters,
- how to fix it, step by step,
- an example where it helps (HTML, JSON-LD, robots.txt, server configuration),
- its impact and effort, so you can start with the quick wins.
